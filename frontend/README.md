# Frontend do Portal de Cursos

Veja o [README principal](../README.md) para instalação, comandos, rotas e fluxo de branches.

Nesta pasta você também pode executar `npm ci`, `npm run dev`, `npm run lint`, `npm test`, `npm run build` e `npm run check:views`.

`check:views` requer um build recente e gera HTML estático dos componentes reais para revisão em `reports`. Esses arquivos não são rotas públicas de simulação.
